# ZeroQ

Serverless, peer-to-peer message queue that replaces Kafka and AWS SQS at near-zero cost.

## Features
- WebRTC DataChannels for direct message delivery
- Pub/Sub and Work Queues
- IndexedDB for durable persistence
- Discovery server for peer connections
